# مشروع لانشر Apple TV 4K لشاشات Android TV

مشروع متكامل ومصمم بأعلى معايير السلاسة (60 FPS) بلغة Kotlin، متوافق مع Android 5.0 (API 21) فما فوق وصولاً لأحدث إصدارات Android TV و Google TV.

---

## 🚀 طريقة التجميع وتصدير ملف APK المباشر:

### الطريقة الأولى: عبر Android Studio (الأسهل والأضمن):
1. قم بتحميل ملف المشروع (.ZIP) من هذا الموقع وافتحه في أي مجلد على حاسوبك.
2. افتح برنامج **Android Studio** واختر **Open** ثم حدد مجلد المشروع المستخرج.
3. انتظر ثوانٍ معدودة حتى تكتمل عملية مزامنة **Gradle Sync**.
4. من القائمة العلوية اضغط على:
   `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`.
5. سيظهر لك إشعار في الأسفل اضغط على **locate** وستجد ملف `app-debug.apk` جاهزاً للتثبيت المباشر!

---

## 📺 طريقة تثبيت اللانشر على شاشة التلفزيون (Android TV / Fire TV / Mi Box):

### خيار 1: عبر فلاش ميموري (USB):
1. انقل ملف `app-debug.apk` إلى وحدة تخزين USB.
2. ضع الـ USB في منفذ الشاشة وافتح أي برنامج تصفح ملفات (مثل File Commander أو X-plore).
3. اضغط على ملف الـ APK واختر **Install** (تثبيت).

### خيار 2: عبر الشبكة لاسلكياً بأمر ADB:
```bash
adb connect <IP_ADDRESS_OF_TV>
adb install -r app-debug.apk
```

---

## 🔒 كيفية تعيينه كاللانشر الافتراضي الدائم ومنع الرجوع:
1. عند الضغط على زر **Home** (أيقونة البيت) في ريموت التلفزيون، ستسألك الشاشة لاختيار اللانشر الافتراضي.
2. اختر **Apple TV 4K Launcher** ثم اختر **Always** (دائماً).
3. الكود البرمجي يتضمن حماية تلقائية مدمجة تمنع الخروج العرضي بزر الرجوع (Back) لضمان ثبات الواجهة السينمائية.
